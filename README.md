🍊  Landing Page - Fanta 

Este projeto é uma landing page interativa que desenvolvi com o objetivo de praticar JavaScript, principalmente na parte de animações e manipulação de elementos na tela.

A página foi construída utilizando **HTML, CSS e JavaScript**, com o auxílio da biblioteca **GSAP** para criar animações sincronizadas com o scroll, trazendo uma experiência mais dinâmica e moderna.

## 🚀 Funcionalidades

* Animações com base no scroll utilizando GSAP + ScrollTrigger
* Movimentação e rotação de elementos na tela
* Seções com transições suaves
* Layout organizado com foco visual

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* GSAP (ScrollTrigger)
